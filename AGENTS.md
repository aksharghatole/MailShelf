# MailShelf development rules
Use Kotlin and Jetpack Compose. Keep all account credentials local, encrypted with Android Keystore, never log or commit secrets. Never request ordinary Google passwords. No server, analytics or ads. Use TLS with hostname verification. Default to read-only mail operations; do not mark read or delete messages implicitly. Treat email bodies as untrusted plain text. No artificial account caps; bound concurrency, per-request page size and memory instead. Do not claim capacity until benchmarked. Keep build and unit tests green. Prioritize OAuth, paginated full inbox/search, configurable bounded cache, biometric lock, privacy-safe notifications and background sync. No production credential tests in CI.
